# Roadmap

## MVP

- Native macOS menu bar app.
- Microphone recording.
- System audio recording where macOS allows it.
- Local session directory layout.
- Mixed audio export.
- Metadata file per recording.
- Local lifecycle logs.

## Later

- Stronger call detection rules.
- Better local recording browser.
- External storage upload for heavy files.
- T-Orbit metadata sync.
- Transcripts and notes.
- Team permissions.
- Retention policies.
- Encryption.

## Explicitly Not In MVP

- Screen recording.
- Cloud upload.
- Telegram integration.
- AI transcription.
- Windows support.
- T-Orbit backend sync.
