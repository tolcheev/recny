Recny сохраняет звук звонка на Mac. После встречи вы можете запустить распознавание речи и получить редактируемые заметки. Названия кнопок ниже приведены на английском, как в приложении.

01 / До установки

Что понадобится

  • Mac с Apple Silicon и macOS 15 или новее. Intel Mac эта сборка не поддерживает.
  • Доступ к микрофону, системному звуку и папке записей.
  • Для расшифровки и заметок: интернет на время установки зависимостей и загрузки моделей, затем можно работать офлайн.
  • Не менее 10 GiB свободного места для обеих моделей, среды выполнения, временных загрузок и результатов. Место под сами записи нужно дополнительно.

Модели не входят в DMG. Без них запись звонков работает, а локальная обработка остаётся недоступной.

Локальные модели проверялись на MacBook с M4 Pro, 24 GiB памяти и macOS 26.5.2. Это отдельная конфигурация проверки, а не замер скорости для всех Mac. Windows 0.2.5 beta не поддерживает функции из разделов о расшифровке и заметках.

02 / Установка

Перенесите Recny в Applications

  1. Скачайте Recny 0.1.9 для macOS, DMG. Также доступен ZIP с приложением.
  2. Откройте DMG и перетащите Recny.app в Applications («Программы»). Для ZIP распакуйте архив и перенесите приложение в ту же папку.
  3. Запустите Recny из Applications. При предупреждении macOS проверьте, что файл скачан из репозитория tolcheev/recny. Откройте System Settings › Privacy & Security («Системные настройки › Конфиденциальность и безопасность»), найдите блок Recny и выберите Open Anyway («Всё равно открыть»). Подтвердите запуск в следующем диалоге.
  4. Открывайте окно приложения через значок Recny в строке меню и пункт Show Window. Настройки доступны там же через Settings.

Сборка подписана ad-hoc и не прошла нотариальную проверку Apple. Это причина предупреждения при первом запуске. Глобально отключать Gatekeeper или защиту macOS не нужно. Порядок разрешения запуска у Apple.

03 / Доступ к звуку

Разрешите запись

Recny показывает, какой доступ ещё нужен. Пока обязательное разрешение отсутствует, запуск записи заблокирован.

  • Microphone. Разрешите микрофон в системном запросе. После отказа включите Recny в разделе Microphone настроек конфиденциальности.
  • Screen & System Audio Recording. Разрешите Recny доступ к системному звуку. Название раздела зависит от версии и языка macOS. Звонок сохраняется как аудио; видеозаписи экрана нет. В приложении отдельно есть ручная команда для скриншота.
  • Папка записей. Проверьте доступность папки. При необходимости выберите другую через Settings › Storage › Change Location.
  • Перезапуск. Когда Recny показывает требование перезапуска, нажмите Restart App либо завершите приложение и снова откройте его из Applications.

После перезапуска проверьте статус Recording permissions ready. Разрешение macOS само по себе не подтверждает, что в записи слышны оба участника: сделайте короткую пробу.

04 / Проверка звука

Сделайте первую запись

  1. В Settings › Recording проверьте выбранный микрофон. Режим Auto, recommended использует внешний или встроенный микрофон. Микрофоны AirPods и других Bluetooth-гарнитур заблокированы для записи; для своего голоса используйте микрофон Mac либо внешний.
  2. Предупредите участников о записи. Нажмите Start Recording, произнесите несколько фраз и проверьте звук собеседника.
  3. Нажмите Stop Recording. Дождитесь завершения обработки аудио, затем откройте запись в Records и прослушайте её.
  4. Для следующих звонков настройте Settings › Auto-start: Off отключает автостарт, Ask first запрашивает подтверждение, Auto запускает запись при обнаружении устойчивой активности звонка.

Автостарт зависит от приложения звонка и условий обнаружения. Когда звонок не распознан, используйте ручной запуск. Автостарт записи не включает автоматическую расшифровку.

05 / Один раз перед обработкой

Подготовьте локальные модели

Parakeet распознаёт речь, Qwen3 4B создаёт заметки по тексту. Обе модели загружаются только по вашей команде в настройках. Recny не скачивает их при открытии записи и не отправляет запросы во внешний AI-сервис.

Parakeet: речь в текст

  1. Установите Homebrew по официальной инструкции, если команды brew ещё нет. Этот шаг нужен для установки дополнительных инструментов.
  2. Откройте Settings › Local transcription и нажмите Copy Install Command. Выполните скопированную команду в Terminal:
brew install uv ffmpeg && uv tool install parakeet-mlx -U
  1. Вернитесь в настройки, нажмите Refresh, затем Prepare Parakeet Model. Дождитесь окончания загрузки mlx-community/parakeet-tdt-0.6b-v3.
  2. Проверьте статус parakeet-mlx is ready. и отметку Ready. Теперь доступна отдельная расшифровка без заметок.

Qwen3 4B: текст в заметки

  1. В Settings › Local Notes нажмите Copy Runtime Install Command. Выполните скопированную команду в Terminal. Она создаёт отдельную среду Python 3.11 в ~/Library/Application Support/Recny/LocalAI/runtime и устанавливает mlx-lm==0.32.2 с lm-format-enforcer==0.11.3.
  2. Нажмите Check Setup. Должен появиться статус Local runtime installed. Системный Python эта установка не заменяет; сервер запускать не нужно.
  3. Нажмите Download & Prepare Model. Recny загрузит mlx-community/Qwen3-4B-Instruct-2507-4bit в ~/Library/Application Support/Recny/LocalAI/notes-model. Загрузка может занять несколько минут.
  4. Дождитесь статуса Local notes model ready. Для проверки или восстановления модели позже используйте Verify / Repair Model.

Для одной расшифровки достаточно Parakeet и ffmpeg. Qwen и среда Local Notes нужны только для заметок. Обработка подготовленными моделями работает без интернета и API-ключа. При неполной установке Recny покажет ошибку.

06 / После встречи

Получите расшифровку и заметки

  1. В Records выберите завершённую запись и откройте Transcript & Notes.
  2. В Notes preset выберите назначение заметок. Meeting собирает темы, решения, задачи и открытые вопросы. Interview организует материал собеседования. Mentoring подходит для обсуждения на менторской сессии.
  3. Нажмите Process Locally. Recny сначала распознает аудио, затем создаст заметки. Ход работы отображается в этом же окне.
  4. Откройте вкладку Transcript для текста или Notes для заметок. Сохранённые результаты доступны при следующем открытии записи.

Нужен только текст

Выберите More › Transcribe Only. Модель заметок для этой команды не требуется. Поле Search transcript ищет слова в сегментах расшифровки, а кнопка с временем переводит проигрыватель к соответствующему месту.

Нужны заметки другого типа

Выберите другой Notes preset и нажмите More › Regenerate Notes. Recny использует уже проверенную расшифровку и не повторяет распознавание речи. Старые текстовые расшифровки сначала нужно создать заново через Transcribe Only, чтобы связать их с аудио.

Interview создаёт структурированный черновик по собеседованию. Он не гарантирует экспертную оценку ответов или корректные исправления. В смешанном системном аудио Recny не определяет отдельных говорящих.

07 / Работа с результатом

Проверьте и сохраните заметки

Нажмите ссылку на источник в заметках: Recny откроет фрагмент расшифровки и перейдёт к его времени в аудио. Связь с фрагментом помогает проверке, но не доказывает, что модель верно поняла слова. Она может перепутать ответственного или превратить план в обязательство.

  1. На вкладке Notes включите Edit Markdown и исправьте текст. Нажмите Save, чтобы сохранить изменения в записи.
  2. Кнопка Copy копирует текст заметок в буфер обмена, включая текущие правки.
  3. Нажмите Export Markdown… и выберите папку вне папки этой записи. Экспорт создаёт отдельный файл notes.md. Его последующее редактирование не меняет заметки внутри Recny.
  4. Перед повторной генерацией сохраните правки. При запросе Unsaved notes выберите Save and Continue, Discard Edits and Continue либо Keep Editing. Последний вариант возвращает к редактированию.

Предыдущие сохранённые версии Markdown остаются в transcript/history/. Если аудио или расшифровка изменились, старые ссылки на источники отключаются. Сначала создайте актуальную расшифровку, затем перегенерируйте заметки.

08 / Очередь обработки

Отмена и повторный запуск

Recny обрабатывает задания последовательно, в том числе из разных окон библиотеки. Закрытие окна Transcript & Notes оставляет задание в работе. Для остановки нажмите Cancel Processing.

После ошибки, отмены или прерывания доступна кнопка Retry. Устраните указанную причину перед повтором. При ошибке генерации заметок завершённая расшифровка сохраняется; для создания только заметок используйте More › Regenerate Notes.

После перезапуска приложения незавершённое задание получает статус прерванного. Оно не возобновляется самостоятельно. Длинные записи обрабатываются частями, поэтому требуют больше времени и могут давать длинные заметки с повторяющимися фактами.

09 / Хранение

Где лежат файлы

Папка по умолчанию: ~/Recordings/TOrbitRecorder/. Историческое название сохранено для совместимости. Откройте её кнопкой Open Library Folder в Records или Settings › Storage.

source/mic.m4a
source/system.m4a
Исходные дорожки микрофона и системного звука.
export/mixed.m4a
Общий аудиофайл для прослушивания.
metadata.json
Метаданные записи.
transcript/
Текст распознавания, SRT/VTT, сегменты с временем, заметки notes.md и notes.json, история правок и состояние обработки.

Recny не загружает аудио, расшифровки и заметки в облако и не синхронизирует их с T-Orbit. Установка инструментов и моделей обращается к внешним репозиториям. Подготовленная локальная обработка использует файлы на Mac.

Файлы не шифруются самим Recny. Храните их в папке с подходящим доступом. Автоматического удаления записей нет.

10 / Когда что-то не работает

Проверьте причину

Кнопка Start Recording недоступна

Проверьте сообщение о блокировке в главном окне. Разрешите микрофон и системный звук, убедитесь в доступности папки и выполните перезапуск, если Recny его запросил. Порядок действий есть в разделе о разрешениях.

В записи не слышно меня или собеседника

Проверьте выбранный микрофон в Settings › Recording и системное разрешение на запись звука. Микрофон Bluetooth-гарнитуры не используется. Прослушайте отдельные файлы source/mic.m4a и source/system.m4a, чтобы определить, в какой дорожке нет звука.

Terminal сообщает command not found

Для brew завершите установку Homebrew и выполните шаги настройки, которые показывает его установщик. Для uv или ffmpeg повторите команду из Copy Install Command. После успешной установки нажмите Refresh в Local transcription.

Process Locally недоступна

Проверьте, что у записи есть аудиофайл, Parakeet готов и Local Notes показывает Local notes model ready. В окне документов нажмите Check Setup. Для текста без Qwen используйте More › Transcribe Only. На время обработки этой записи повторный запуск блокируется.

Модель не скачалась или установка неполная

Проверьте интернет и свободное место. В Local Notes повторите Download & Prepare Model или Verify / Repair Model. Для Parakeet используйте Prepare Parakeet Model. При ошибке зависимостей повторите соответствующую команду установки, затем проверьте статус. Во время обработки записи подготовка модели заметок недоступна.

Кнопки времени или ссылки на источники не работают

У старой расшифровки может не быть проверенной связи с аудио. Изменение файла также делает прежнюю связь недействительной. Выполните More › Transcribe Only, затем More › Regenerate Notes.

Заметки неточные, слишком длинные или с повторами

Проверьте спорные фразы по ссылкам на источник и по аудио. Исправьте заметки через Edit Markdown. Повторная генерация может изменить формулировки, но не гарантирует правильный смысл. При превышении ограничений обработки Recny сообщает ошибку и не заменяет корректно сохранённые заметки неполным результатом.

Появилось Documents changed on disk

Документы изменены вне текущего окна. Скопируйте нужные несохранённые правки, затем нажмите Reload и разберите запрос о сохранении. Не выбирайте Discard Edits and Continue, если хотите оставить текущий текст.

Ошибка осталась после проверки

Откройте Diagnostics через меню Recny и раздел Logs. В сообщении об ошибке на GitHub укажите версию macOS, модель Mac, версию Recny и шаги до ошибки. Перед публикацией проверьте диагностические данные: GitHub Issues видны всем. Запись разговора и текст расшифровки прикладывать не нужно.

11 / Новая версия

Как обновить Recny

  1. Откройте Settings › About › Check for Updates. При доступном обновлении используйте Download Update или Release Page.
  2. Остановите запись и дождитесь окончания локальной обработки. Завершите Recny через Quit.
  3. Скачайте новую сборку из GitHub Releases, откройте DMG и замените Recny.app в Applications.
  4. Запустите приложение. Проверьте версию в Settings › About, доступность записей и состояние моделей. При повторном запросе macOS разрешите нужный доступ.

Замена приложения не требует удаления папки записей или моделей. Обновления macOS и Windows выпускаются отдельно.
