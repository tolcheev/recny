Recny Исходный код

Бесплатно · Open source · Всё локально

Запись созвона включается сама.

Recny замечает звонок в поддерживаемом приложении, записывает микрофон и звук компьютера в отдельные файлы, затем собирает общий аудиофайл. Записи остаются на вашем компьютере.

Скачать для macOS v0.1.8 · Apple Silicon Скачать для Windows v0.2.5 beta · x64
01

Автостарт

Recny ждёт устойчивую активность звонка и запускает запись. Ручная кнопка тоже есть.

02

Два источника

Микрофон и системный звук сохраняются отдельно. Общий файл создаётся после остановки.

03

Локальные файлы

Приложение не загружает разговоры в облако. Папку хранения можно открыть из Recny.

04

Открытый код

Клиенты для macOS и Windows опубликованы на GitHub по лицензии MIT.

Установка

macOS

macOS Sequoia, Mac с Apple Silicon

  1. 01Скачайте DMG и перетащите Recny.app в Applications.
  2. 02Откройте Finder → Applications. Нажмите на Recny правой кнопкой и выберите Open.
  3. 03Если macOS снова заблокирует запуск, откройте System Settings → Privacy & Security и нажмите Open Anyway.
  4. 04Разрешите доступ к микрофону и Screen & System Audio Recording.

Сборка подписана ad-hoc и не прошла Apple notarization, поэтому macOS показывает предупреждение при первом запуске. Отключать Gatekeeper не нужно.

Установка

Windows

Windows x64, экспериментальная beta

  1. 01Скачайте ZIP и распакуйте его в постоянную папку.
  2. 02Запустите Recny.exe.
  3. 03Если появится SmartScreen, нажмите More info, проверьте источник файла и выберите Run anyway.
  4. 04Открывайте Recny через значок в системном трее.

У Windows-версии пока нет установщика. Это beta без полного паритета с macOS; запись микрофона и системного звука работает через WASAPI.

Хранение

Разговор остаётся у вас.

На macOS записи лежат в ~/Recordings/TOrbitRecorder/. На Windows — в %USERPROFILE%\Recordings\Recny\.

В приложении нет облачной загрузки, синхронизации с T-Orbit и фоновой аналитики записей. Перед записью предупредите участников созвона.
