Установка

macOS

macOS 15 или новее, Mac с Apple Silicon

  1. 01
    Скачайте DMG и перетащите Recny.app в Applications.
  2. 02
    Откройте Recny из папки Applications.
  3. 03
    При блокировке первого запуска проверьте источник файла. В System Settings › Privacy & Security разрешите запуск через Open Anyway.
  4. 04
    Разрешите доступ к микрофону и Screen & System Audio Recording. Подробнее о разрешениях.

Сборка подписана ad-hoc и не прошла Apple notarization, поэтому macOS показывает предупреждение при первом запуске. Отключать Gatekeeper не нужно. Установка моделей нужна только для расшифровки и заметок.

Установка

Windows

Windows x64, экспериментальная beta

  1. 01
    Скачайте ZIP и распакуйте его в постоянную папку.
  2. 02
    Запустите Recny.exe.
  3. 03
    Если появится SmartScreen, нажмите More info, проверьте источник файла и выберите Run anyway.
  4. 04
    Открывайте Recny через значок в системном трее.

У Windows-версии пока нет установщика. Это beta без полного паритета с macOS; запись микрофона и системного звука работает через WASAPI. Локальной расшифровки и AI-заметок в этой Windows-сборке нет.

Хранение

Разговор остаётся у вас.

На macOS записи лежат в ~/Recordings/TOrbitRecorder/. На Windows — в %USERPROFILE%\Recordings\Recny\.

В приложении нет облачной загрузки, синхронизации с T-Orbit и фоновой аналитики записей. Для подготовки моделей нужен интернет; после установки обработка работает офлайн и не требует API-ключа. Перед записью предупредите участников созвона.
