# Security Policy

## Supported versions

Security fixes target the current macOS release and current Windows beta.

## Report a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting from the Security tab of this repository. Include the affected version, operating system, impact, reproduction steps, and the smallest safe proof of concept.

Do not attach real recordings, transcripts, access tokens, credentials, or private call content. Use synthetic data.

Ordinary bugs belong in the public [issue tracker](https://github.com/tolcheev/recny/issues/new?template=bug_report.yml).
